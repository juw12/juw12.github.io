Why it exists

A small daily ritual of luck.

Hoki is a waving lucky cat (招财猫) for your home screen and your desktop.

Every tap makes the paw wave faster and the glow brighter.

What's inside

What Hoki does.

A cat that waves all day

The raised paw waves on its own, smoothly, in a soft flat-vector style with a moon-gate scene behind it.

Tap for luck

Each tap gives +1 luck (福 / 财 / 运 / 喜), a bell, coins and a luck boost that speeds up the wave.

Lucky numbers

8 发, 28, 88, 168 一路发, 288, 888, 1688 and 8888 trigger a big bell and a blessing.

Today and all time

Counts your luck for today and all time, and shows the next lucky number to reach.

On your home screen

Add it to your phone's home screen. It opens full screen and works offline.

On your Windows desktop

A transparent, always-on-top widget draws the same cat. Click for luck, drag to move, right-click for options.

Questions

Good questions.

What does it run on?

PWA, Windows widget. You can try it in the browser with nothing to install.

How do I get it running?

The commands in the “Windows desktop widget” box above come straight from the README. Paste them into a terminal; the README covers options and troubleshooting.

Where does my data go?

Your counts are saved only on your device.

Does it need admin rights on Windows?

No. There is no install wizard: it is one PowerShell + WPF script that draws the same cat as the web app.

How do I uninstall the desktop widget?

Right-click the cat and choose Quit, then delete %LOCALAPPDATA%\Hoki, %APPDATA%\Hoki and the Start menu shortcut "Hoki Lucky Cat".

Can I show just the cat?

Yes. juw12.github.io/hoki/?widget shows a cat-only view with a transparent background, for a browser side panel or a live-wallpaper tool.

What doesn't it do yet?

A live, animated widget inside the iOS or Android widget area would need a native app, because the system widget APIs don't allow continuous animation. The desktop widget is for Windows only.

Is it finished?

Not yet: it's marked “live” and still changing. The README always has the current state.
